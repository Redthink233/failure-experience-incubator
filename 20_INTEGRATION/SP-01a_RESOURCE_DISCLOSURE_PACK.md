## 6. 结构性发现与风险登记

### 6.1 ✅ 好消息：`R1 ↔ R3` **不需要 NAT 网关**

🟢 官方《函数网络配置和容量说明》列出**五种网络模式**，其中 **"模式2：同时配置公网访问与私有网络"** 明确存在 ⇒ 云函数可以**同时**具备公网访问能力与 VPC 私网访问能力。
⇒ **访问 VPC 内的 PostgreSQL 走私网，无需引入 NAT 网关**（避免一笔额外按量资源与"额外网络产品"报备）。
补充（🟢）：函数网关在**同主账号同地域**下按**子网粒度复用**，每个网关占你 VPC 内 **1 个 IP**（不额外计费）；函数实例不直接占用你 VPC 的 IP。

### 6.2 ⚠️ 同地域同 VPC 是硬要求

🟢 云数据库 PostgreSQL 购买页网络参数为**私有网络**；同一 VPC 下不同可用区**内网互通**。
⇒ **R1 与 R3 必须同地域**，R1 的 VPC 配置必须指向 **R3 所在的 VPC / 子网**。

### 6.3 🔴 与 PROPOSED 规格冲突：Web 函数默认触发器**后端超时固定 15 s**

🟢 官方《Web 函数计费说明》对比表：**默认创建（基础型 API 网关）后端超时时间 = 15 s，不可修改**；**自定义创建（标准型 API 网关）可配置**。
**冲突**：任务书 §六 的 PROPOSED 起点是 **Timeout 30 s** ⇒ 在"默认创建"路径下**无法实现**。
**两条可实现路径（均引入 API 网关这一额外产品，须你确认）**：
- (a) Web 函数 **自定义创建** + **标准型 API 网关**（可配后端超时；触发器侧按 API 网关标准计费）
- (b) **事件函数 + API 网关触发器**（同上）
🟡 API 网关官方免费额度：**第一年每月前 100 万次调用 + 前 1GB 流量免费**（超出按阶梯计费）⇒ 本次用量（≤1,500 次）应落于免费额度内，**但"本账号是否仍在新用户第一年免费期内"须你核对**。
> 处置：**不自行决定**。请在确认时指明走 (a) / (b) / 或接受"默认触发器 15 s"（后者等于**对 `S-02`/`S-03` 探针级条件的改变**，须你明示）。

### 6.4 ⚠️ R3 的"自动休眠"：**不支持 / 当前产品未提供**

- **R3-a 云数据库 PostgreSQL**：官方购买页与规格文档**均未提供"自动休眠 / 自动暂停 / Serverless"能力** ⇒ **结论：当前产品未提供自动休眠**。
- 🔴 **明确警示**：**不得把旧 Serverless PostgreSQL 的休眠能力迁移过来**（任务书 §八 的要求）；本项目也未采用该旧形态（§2.1）。
- **R3-b（CloudBase）**：官方套餐表对 **MySQL 关系型数据库**写明"**个人版默认开启自动暂停**、标准版及以上支持关闭"；但对 **PostgreSQL 数据库**该列为 `—`（未标）⇒ 🔴 **须控制台确认**，本文件**不推定**其具备自动暂停。
