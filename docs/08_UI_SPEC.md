## S00-01 决策同步（2026-09-17）

> 本节只记录**已被人工决策锁定的界面约束与对应关系**，不进行 UI 设计。页面设计与视觉方案进入 S00-02。

### 1. 已锁定的入口心智（D4）

- 第一屏/录入入口的用户心智应接近"**刚刚哪里没有达到你的预期？**"
- 产品**不得把"填写档案"作为主要用户心智**；结构化整理由 AI 完成，用户只做确认与修改。
- 界面上必须体现两层价值：即时（理解当前失败 + 下一步验证什么）与长期（经验资产沉淀）。

### 2. 已锁定的界面表达要求（D7）

- `Fact｜用户事实`、`Extraction｜AI 结构化解析`、`Inference｜AI 推断` 三类内容必须在视觉上明确区分。
- AI 推断类内容必须显示"AI 推断 / 候选结论 / 待确认 / 待验证"标识，**不得与用户事实呈现为同一形态**。
- 跨记录结论须显示为 `Candidate Insight`，并提供其引用的历史 Attempt 作为证据入口。

### 3. 已锁定的页面 ↔ D9 主链对应关系

| D9 主链环节 | 对应界面区域 |
|---|---|
| ① 自然语言输入一次失败尝试 | 录入入口（D4 心智） |
| ②③ AI 解析 + 用户修改/确认 | 解析确认区 |
| ④⑤ 候选原因 + 用户确认保存 | 原因确认区 |
| ⑥⑦ 检索相关历史 + 相似点与差异点 | 相似对比区（必须同时呈现相似点与差异点） |
| ⑧ 可复用经验提炼 | 经验区（标注 Candidate Insight） |
| ⑨⑩ 新假设生成 + 证据追溯 | 假设区（含支持/反驳条件、引用的历史 Attempt） |

### 4. 其他已锁定约束

- **D8**：预置示例数据必须有明确的"Demo / 示例数据"标识，不得伪装为真实用户数据。
- **D3**：页面清单中不出现团队、成员、权限、角色、管理员相关入口。
- **D10**：不出现成功经验管理中心、成功案例库、完整实验管理系统入口；结果状态（Failed / Partial / Success / Unknown）可在 Attempt 层展示，但主入口仍围绕未达预期。
- **R3**：不出现图谱可视化系统。

### 5. 待 S00-02 完成

- §1 视觉风格基调、§2 页面清单优先级与信息架构、§3 关键交互、§4 原型线框。
