- 待填写：场景的触发时机、持续时长、设备与网络条件

## 3. 用户旅程（高层）

> 详细交互流程见 04_USER_FLOW.md

- **已锁定（D9 P0 主链）**：输入一次失败尝试 → AI 结构化解析 → 用户确认 → 候选原因 → 保存 Attempt → 检索相关历史 Attempt → 展示相似点与差异点 → 提炼可复用经验 → 生成可验证新假设 → 假设可追溯到历史证据。
- 本文档原有的"记录失败 → 解析归档 → （时间推移）→ 新问题出现 → 检索关联 → 获得建议方向"作为历史提案保留；其中"建议方向"精确化为"可验证假设"（D5）。
