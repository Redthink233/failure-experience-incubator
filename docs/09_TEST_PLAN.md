### 1. `D-055`（LLM Request Path）对应验收点（`AC-144` – `AC-152`）

| **AC-146** | **C｜Proxy 只能访问服务器注册的受控 Provider endpoint** | Proxy 的目标**只能**由 `provider_id → 服务器端已注册 Adapter → 固定 / 严格受控 Provider Host` 决定；🔴 **不得由请求中的任何字段决定最终目标**；🔴 **不得存在 `provider_id` + 任意 target URL 的组合** | `D-055` 五 |
| **AC-147** | **D｜Custom `Base URL` 不得通过通用 Vercel Proxy** | 对 Custom / OpenAI-compatible / 用户自定义 `Base URL`：**默认 = Browser Direct Only**；🔴 **不得出现** `Browser → Vercel → 用户任意 URL`；🔴 **不得提供 `Generic Arbitrary URL Proxy`** | `D-055` 四 |
| **AC-148** | **E｜Proxy 不接受 arbitrary target URL** | Proxy 接口**不得接受** client 提交的 `target_url` / `base_url` / `host` / `scheme` 并据其代请求；🔴 **即使 client 构造了该字段，Proxy 也不得基于该字段决定目标**（该字段**必须被忽略或拒绝**） | `D-055` 四 / 五 |
| **AC-149** | **F｜Proxy 保持 `THIN`** | Proxy **只承担** request normalization / provider adapter forwarding / response normalization / timeout·error mapping / 必要的 schema transport；🔴 **不得承担** Workspace / `Attempt` / `Insight` / `Hypothesis` 持久化；🔴 **不得存在** Experience database / Cloud user database；🔴 **不得成为任何科研主数据的存储点** | `D-055` 三；`D-053` |
| **AC-150** | **G｜不可用 Provider 必须明确失败，不得降级为不安全 Proxy** | Custom `Base URL` 既**无法 Browser Direct** 又**没有安全预定义 Proxy Adapter** 时：**必须给出明确失败提示**（表达 `Provider connection unsupported under current browser constraints` 之含义）；🔴 **不得静默改走通用 Vercel Proxy**；🔴 **不得为"支持所有 Provider"降低 SSRF / Proxy 安全边界** | `D-055` 六 |
| **AC-151** | **H｜Proxy 私有 / 链路本地 / 非 `https` 目标防护** | Proxy **必须拒绝**目标为 `localhost` / `127.0.0.0/8` / `::1` / RFC1918（`10/8`、`172.16/12`、`192.168/16`）/ link-local（`169.254/16`，含 metadata endpoint 形态）/ **非 `http(s)` scheme**；🔴 **不得跟随重定向到 allowlist 之外**；🔴 **不得采用"黑名单 + 默认放行"** | `D-055` 四 / 五（SSRF / Open Proxy 防护要求） |
| **AC-152** | **I｜V1 不为 Provider 预置服务端固定 Key** | 🔴 **不得存在**产品侧预置的固定 server secret 用于代表用户调用 Provider；**Proxy 只是传输通道、不是 Key 持有方**；`Credential` **始终来自用户**（其生命周期见 `AC-153`–`AC-162`） | `D-055` 七；`D-056` |
